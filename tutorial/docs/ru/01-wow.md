# Pg-schema за 15 минут

Цель: за один проход создать учебную БД, сгенерировать схему и запустить примеры.

Все команды выполняются из корня репозитория `pg-schema` (там, где лежат
`cabal.project` и `Makefile`).

## Шаг 0. Строка соединения

Генератор и приложение берут строку соединения из переменной `PG_CONN`.
Учебная БД называется `tutorial`:

```bash
export PG_CONN='dbname=tutorial'
```

Если PostgreSQL требует хост, пользователя или пароль, добавьте их в эту
строку, например `dbname=tutorial host=localhost user=postgres`.
Без `PG_CONN` приложение подключается к `dbname=tutorial`, а генератор
ничего не делает.

## Шаг 1. Создать учебную схему в PostgreSQL

```bash
make tut-db-init
```

Команда создаёт БД `tutorial`, если её ещё нет, и применяет
`tutorial/sql/00-create-schema.sql`. Скрипт сначала удаляет схему `tut`,
так что повторный запуск даёт чистую БД.

Проверка:

```bash
psql "$PG_CONN" -c "\dt tut.*"
```

Ожидаем таблицы: `users`, `projects`, `tasks`, `task_events`.

## Шаг 2. Сгенерировать `Sch.hs`

Генератор `tutorial/app/generator/Main.hs` вызывает `updateSchemaFile` и
пишет модуль схемы в `tutorial/app/app/Sch.hs`:

```bash
cabal run tutorial:generator
```

Проверка, что файл появился или обновился:

```bash
ls -la tutorial/app/app/Sch.hs
```

## Шаг 3. Запустить примеры

```bash
cabal run tutorial:tutorial
```

Ожидаем в выводе:

- вставку и выборку пользователей (`insertSch`, `selectSch`);
- вставку проекта с вложенными задачами и событиями через `insertJSON`;
- текст SQL-запросов.

Шаги 1–3 одной командой (вывод сохраняется в `tutorial/out/tutorial.txt`):

```bash
make tut-run
```

## Мини-checklist после главы

- [ ] Схема `tut` создана.
- [ ] `Sch.hs` сгенерирован.
- [ ] Дерево данных вставилось одной операцией.
- [ ] В выводе виден текст SQL-запросов.
